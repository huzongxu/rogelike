# 《回响深渊》UI 设计规范 v1

> 竖屏微信小游戏(480×854 逻辑分辨率),暗黑+霓虹风格,匹配"深渊/尸潮/回响"世界观。
> 本文档为设计基准,同步落地到 game.ts 渲染。

---

## 1. 设计语言

**关键词**:深渊暗调 · 霓虹点缀 · 清晰层级 · 一手操作

- **基调**:深蓝黑底(#0B0E14 ~ #131826),内容浮在"玻璃层"上(半透明面板 + 细边框)
- **点缀**:霓虹色仅用于关键信息(品质/货币/状态),克制使用
- **层级**:背景(战场)→ 面板(玻璃)→ 内容(文字/按钮)→ 强调(霓虹描边)
- **手感**:按钮有大点击区(≥44px),反馈即时(按下变亮)

## 3. 字体系统

| 级别 | 规格 | 用途 |
| --- | --- | --- |
| H1 | bold 22px | 界面标题(商店/扭蛋/天赋) |
| H2 | bold 15px | 区块标题 |
| Body | 13px | 主要信息 |
| Caption | 11px | 说明/辅助 |
| Micro | 9-10px | 徽标/参数 |

统一 `system-ui, sans-serif`;数字信息(金币/伤害)可用 bold 提高可读性。

## 3b. 竖屏设计令牌 v2(2026-08-28 全量翻版,落地于 `cocos/assets/scripts/game/ui/theme.ts`)

> v1 字阶面向 560 桌面审阅;v2 是运行时唯一事实源,为手机触控放大一档,并与可变设计高适配。

- **设计空间**:宽恒 560;`logicalH = clamp(round(560·winH/winW), 996, 1246)`——手机竖屏顶满(1080×2340→1212),桌面 16:9 保持 996 居中列,信箱区由场景背景 cover 满溢。**战场/竞技场恒锁 560×996**(刷怪为绝对时间制,面积不随屏变),高屏多出的高度是底部 HUD 坞。
- **字阶 `fs`**:display 28 / title 22 / section 16 / body 14 / muted 13 / micro 12;字体串一律走 `F(px, bold)`。
- **控件档 `ui`**:页面边距 pad 14;面板返回钮 72×34(右上 y22,`hitPanelBack` 共用命中);主 CTA ≥52h、次级 ≥34h、触控底线 44;列表行 48–100。
- **分布助手**:`spreadRows(n, y0, y1, minH, maxH, maxGap=20)` 列表均匀分布(富余摊行距、超 maxGap 落列表尾留白,轨道型如通行证档位放大 maxGap);面板普遍「头部固定 + 尾块贴底 + 中部列表吃剩余」;商店例外为「自上而下顺排 + CTA 贴底」,防高屏中段空洞。
- **行内居中**:`rowTextY(y, h, px)` 或两线基线 `h/2∓`;**draw 与 hit-test 必须共用同一 layout/助手,禁止各自重推坐标**。



- **主按钮**:高 44px,圆角 4,底 #1D3D2E,描边 2px `action-primary`,文字 `action-primary`;按下 → 底变亮
- **次按钮**:高 26-28px,底 #2A3D55,描边 1px rgba(255,255,255,.3)
- **危险按钮**:底 #3A2222,描边 `action-danger`
- **卡牌**:品质色顶条(4px)+ 品质色描边;名称居中 bold;参数 Caption 灰
- **列表行**:高 26-30px,选中 → 底色 rgba(90,200,250,.16) + 描边 #5AC8FA
- **货币栏**:图标+数值,右对齐;金色/紫色/蓝色区分

### 5.6 通行证 / 结算 / 胜利
- 通行证:档位行(免费左/高级右,当前档高亮,可领取金色脉冲)
- 阵亡:大标题红"阵亡" + 数据(生存/击杀/回响)+ 三按钮(重开/天赋/菜单)
- 胜利:大标题金"通关!" + 奖励列表(券/回响/星尘图标)+ 返回菜单

## 6. 动效规范

- 货币变化:数字滚动 + 飘字(+10 金)
- 卡牌购买:卡牌飞入武器栏
- 升品:白光闪 + 品质色升级粒子
- 狂潮:屏幕边缘红色脉冲
- Boss 出场:全屏震屏 + 红字警告
- 按钮按下:0.1s 亮度提升

## 7. 无障碍/手感底线

- 所有可点目标 ≥ 44×44px(小按钮加内边距)
- 文字对比度 ≥ 4.5:1(深底浅字)
- 关键状态(挂机/手动、槽满)有文字提示,不只靠颜色
- 战斗 HUD 不遮挡中心战场(信息贴边)
