## 0. 一句话结论

数值墙打通后，游戏最大的结构性问题不是数值，而是两个：**局内 20 章每一章体验完全一样**（没有重开的理由）、**"赛季关卡式"只是文档口号、赛季壳一行代码没有**（没有明天回来的理由）。推荐两条主线：

- **P0-A 章型差异化 + Boss 机制化**：让 20 章内部有节奏起伏（最便宜，见效最快）。
- **P0-B 赛季壳**：14 天日历门控 + 每日首通 + 通关星数 + 赛季结算（留存骨架，产品定位的兑现）。

两者同一迭代做：A 是 B 的"每日内容"，且都不碰今天刚标定的数值墙。

## 3. P0-A 章型差异化 + Boss 机制化

### 3.1 章型表（新增纯函数 `chapterType(chapter, stage)`）

| 章型 | 位置 | 规则（只在本章生效） | 额外奖励 |
| --- | --- | --- | --- |
| 普通章 | 其余 | 现状 | 现状 |
| 精英章 | 第 5 / 10 / 15 章 | 本章 `spawnScale ×1.3` + 敌情强制 `prefer=elite`（hpBuff 0.4、倾向 0.3）+ 开局 burst ×1.5 | 章间商店 +1 次免费刷新 + 15 金 |
| 宝箱章 | 第 7 / 14 章 | 本章 `spawnScale ×0.5` + 混入 25% 金怪（新 EnemyKind `goldkind`：hp ×0.6、`xp=8` → 单只 16 金） | 暴击击杀金怪触发"金币雨"（本章后续掉落 +20%） |
| Boss 章 | 第 20 章 | **7 关全部有 Boss**（补偶数关空洞）：奇数关 = 深渊领主满机制；偶数关 = 弱化变体（hp ×0.7、无死亡分裂） | 通关 |

接入点：`Game.nextChapter()`（game.ts:1303）读章型决定 intel / burst / 本章 spawnScale；开局 burst 公式 `6+floor(ch/3)` 保持。

### 3.2 Boss 机制化：三阶段 + 预警

- **P1（100%–60%）**：追击 + 反射 15%（现状行为）。
- **P2（60%–25%）**：新增"地面震击"——蓄力 1.2s（红色圆环预警特效）→ 范围 220px 新星 80 伤害；同时每 6s 召唤 2 腐尸。
- **P3（<25%）**：狂暴：移速 ×1.4、召唤间隔减半；死亡分裂 2 幼体（现状）。
- 偶数关变体：跳过 P2。
- 实现：enemy 增 `phase / telegraphTimer` 字段，复用 `updateSpecial` 钩子；`BattleContext` 加 `onBossPhase` 回调驱动 UI（血条变色/阶段横幅）。**美术增量 = 0**（预警环用代码粒子，Boss 血条框已在 ART-REQUIREMENTS P1）。
- 数值依据：80 伤害对标墙标定基线（新手局稳态 HP 75–95，220px 躲避半径实测可达）。
- 实现状态（S2 已落地）：`updateBoss`（enemy.ts）纯逻辑状态机 + `BossEvents` 回调；game.ts 接线召唤/阶段横幅/震击伤害与红色预警环；7 关第 20 章全部出 Boss（偶数关 = 弱化变体：hp ×0.7、跳过 P2、无死亡分裂）；断言见 tests/boss.test.ts（8 例，含单发跳 P2、弱化直入 P3）。
- **Boss 独立血量曲线（S2 补丁）**：旧版所有关卡统一 `220 × waveHpMult(20) = 473hp`，三阶段机制还没展开就被融化（单目标木桩标定：到达态 47.8 dps → 9.9s；神装 119.0 → 4.0s；终局 191.1 → 2.5s）。现改为随关卡增长的独立曲线 `BOSS_HP_CURVE = { base: 2.0, growth: √2 }`（enemy.ts），生成处 `hp ×= bossHpMult(stage)`，偶数关 ×0.7 在其后叠加。目标 TTK：第 1 关 ≈20s、第 7 关 ≈40s（第 20 章 60s 超时判负留裕量）；每关 ×√2（+41%）几何爬坡对齐玩家乘性成长。标定口径 = `measureBossDps` 单目标木桩（确定性：全部 uid 计数归零 + 种子 RNG），守卫见 tests/boss.test.ts（ttk1∈(12,35)s、ttk7∈(24,55)s）。注意：**第 1 关 Boss 血量 473→946 是有意上调**（旧版到达态 10s 击杀同样过易）。

### 3.3 数值接口约定

- 章型倍率（×1.3 / ×0.5）**只作用于单章**，不得折入 `waveHpMult` / 生成间隔 base 曲线——那是今天的标定基线。
- 精英章初稿（×1.6、倾向 0.45）在 balance-sim 中被证伪：新手+商店成长局进章 21s 内阵亡，"台阶"变"处决"；现值为标定后结果（生长型局可迈过第 5 章，第 6 章数值墙接力，见 tests/chapters.test.ts）。
- 金怪金币：`def.xp × 2 = 16`（对比腐尸 2，即 8 倍），宝箱章本章总金币 ≈ +60%。
- balance-sim 已支持章型：`chapterTypes` 选项注入敌情加权 + 章型倍率（默认关闭，不扰动已标定基线）。

## 4. P0-B 赛季壳

### 4.1 骨架

- `seasonStartAt` 时间戳 → `seasonDay = min(14, floor((now − start)/86400) + 1)`。
- 门控：**第 1–7 天只开放第 N 关**（覆盖 `highestStage` 解锁）；**第 8–14 天**主线全开 + 无限关冲榜（`bestWave` 计分）。
- 结算：第 14 天结束 → 赛季结算面板：赛季分 = Σ(关卡星数×10) + bestWave → 兑换星尘 + 限定头像框；新赛季清空星数与赛季分（`highestStage` / 收藏 / 天赋 / 转生永久保留）。
- 存档新字段（**SaveData / EMPTY / loadSave 三处同步**，现无版本迁移机制）：`seasonId, seasonStartAt, stageStars[8], seasonBest, dailyClearedDate, dailyClearedStage`。

### 4.2 每日首通 + 通关星数

- 首通奖励（`dailyClearedDate == today` 判定，**每日 1 次**：当天首次通关任意关卡，记录于 `dailyClearedStage`）：券 ×2 + 回响 ×1.5；重复刷关维持现状奖励 + 通关装备掉落（已实现）。
- 星数判定（1–3 星）：通关 ★ + 剩余生命 ≥50% ★ + 未使用广告复活 ★。
- 3 星一次性奖励：该关卡框（ART P1 头像框批次）+ 券 ×5。
- 星数接入：赛季分来源；通行证进度在现有 `points + dayEcho` 基础上叠加 星数 ×2。
- 实现状态（S3 已落地）：纯函数层 `data/season.ts`（天数/门控/星数/赛季分，13 例断言见 tests/season.test.ts）；存档三处同步 6 个新字段 + `normalizeStars` 脏数据钳制；`syncSeason` 每帧结算翻页（多赛季缺席用 while 循环连续滚），结算面板 `season` 态一次性弹出；`victory()` 结算星数/首通/3 星一次性券；重试与重开绕过赛季门控（`bypassGate`）。§4.3 幻影榜已落地（S5）；头像框与 §4.4 补领/补星未动（后续批次）。

### 4.3 排行榜（诚实 MVP）

`platform/adapter` 目前无网络能力（仅本地存储 + 激励视频）→ 真排行不可行。MVP 做**本地幻影榜**：按 `seasonId` 种子生成 10 个固定名次幽灵分，玩家以 bestWave / 赛季分对照，提示"已超越幻影第 N 名"。后端就绪后接口直插；**不做假联网**。分享卡预留 `rankScore` 参数。

- 落地状态（S5 已落地，2026-08-28）：纯函数层 `data/leaderboard.ts`（`phantomBoard` / `rankAmong`，9 例断言见 tests/leaderboard.test.ts）。口径拍板 = **赛季分**（`seasonScore(stageStars, seasonBest)`），非 bestWave；幽灵分分布 `base = 12 + round(236·(k/9)^1.8) + floor(rng·5)`（Park–Miller LCG，种子 `(seasonId·48271) % 2147483647`），强制严格降序；**审计修订（2026-08-28，§8 #6）后顶两名改独立基准**——次席 213、榜首 233（各 +0–4 抖动），其余仍走原曲线，区间 ≈[13, 237]——1 星首通（10 分）仍第 11 名不空榜，榜首现实可达（全 3 星 210 + 无限关波 31 = 上限 241）。名次口径 = 竞技排名（`1 + 严格大于玩家的条目数`，同分幽灵在前）。展示：主菜单右上「幻影榜 · No.M」入口 → 全屏面板（11 行 = 10 幽灵 + 玩家行金底插入其名次位），诚实副标题「本地幻影 · 非联网数据 · 后端就绪后接入真榜」；胜利面板（`victory` 快照前后对比）与死亡面板（`onDeath` 预期计算 `max(seasonBest, chapter)`，`revive` 时清除——因 `settleRun` 延迟到离开面板才执行）各加一行「已超越幻影第 N 名」，`startRun` / `syncSeason` 翻页时重置。分享卡 `rankScore` 预留**本次延后**：分享功能零实现，不写死代码，文档挂账（§8 决策 #3 一并视为已答：幻影榜作为 MVP 已验收）。

### 4.4 商业化触点（不加新墙）

- 错过当日首通 → 看广告补领（每日 1 次），不花钻石。
- 3 星差最后一项 → "补星"可选钻石消费（5 钻），纯自愿。
- 复活 / 结算双倍维持现状（ADS-DESIGN 点位 ①②）。
- **落地状态（2026-08-28）**：两项触点已实现——**补星**：`STAR_MAKEUP_COST=5` / `canStarMakeup`（仅恰好 2 星可补）；主菜单关卡行「5◆ 补星」按钮（右对齐文本左移 56px 让位，命中矩形固定不依赖画布测量）；扣钻→3 星→走与胜利同源的 `settleThreeStarOnce`（券 ×5 + 首达解锁头像框）。**补领**：每日界面补领行（可领/已补领/已首通三态），看广告领 `makeUpReward(highestStage)`（券 ×2、回响 ×1.5，口径 = 首通），领取即置 `dailyClearedDate=今日`（消耗当日首通防双领），`makeUpDate` 仅用于状态文案；回响走 `splitEcho` 直入 `points`/`dayEcho`，不碰 run 作用域的 `settleEcho`。**头像框**：`save.frames` 记关卡 id，3 星首达解锁，当前为代码绘制金圈占位（胜利面板提示 + 幻影榜玩家行徽标），ART P1 批次换贴图。测试：`season.test.ts`（补星 3 例）/`stages.test.ts`（补领 2 例）/迁移默认值断言。
