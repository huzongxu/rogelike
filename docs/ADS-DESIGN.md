# 广告驱动商业化设计(弹壳特攻队思维 + 数值墙成长)

> 2026-08 落地。参考吸血鬼幸存者(局内构筑)/ 土豆兄弟(武器位)/ 弹壳特攻队(体力闸门 + 激励视频)。
> 核心循环:**体力闸门 → 打关 → 数值墙 → 死亡复活/双倍(广告)→ 通关刷装备 → 收藏基础数值 → 推更高关 → 解锁更高数值装备**。

| 货币 | 来源 | 消耗 | 说明 |

| 金币 | 局内杀怪 | 商店买卡 | 场内货币,不进场外 |
| 回响 | 通关/死亡结算 | 天赋树 | 40% 永久,60% 本日(仅通行证进度) |

| **钻石** | 每日看广告(上限 10/天)/委托辉钻矿脉 | 体力回满/扭蛋券 | **新增**(硬通货) |

## 二、体力闸门(弹壳式硬体力)

- 上限 20,每 6 分钟恢复 1 点(10 小时回满),时间戳结算(`lastEnergyAt`,离线照常恢复)
- 主线消耗随关卡递增:第 1-2 关 5 / 第 3-4 关 6 / 第 5-6 关 7 / 第 7 关 8;无限关 3
- 进入关卡即扣(失败不返还);体力不足弹「体力不足」面板:
  - **看广告 +5 体力**(每日限 5 次)
  - **钻石回满**(10 钻)
  - 关闭回主菜单
- HUD 与主菜单货币栏常驻显示 ⚡ x/20

## 四、数值墙成长(通关刷装备 + 每日天赋)

### 4.1 通关装备掉落(基础数值来源)
- 通关第 N 关掉落 `1 + floor(N/2)` 件装备,装备等级 = 关卡 id(第 7 关掉 level 7 装备,数值 = 1+(N-1)×12%)
- 掉落进永久收藏:`同 name+同 quality` 判定,重复转星尘(与扭蛋一致),新收藏入图鉴
- **收藏图鉴提供全局基础数值**:每件按品质攻击 +2/4/6/9/15%、生命 +1/2/3/5/8%(扭蛋界面显示)
- **关卡解锁数值**:商店卡等级 = `max(章节+1, 已解锁最高关卡)`;扭蛋等级 = `5 + (最高关卡-1)` —— 通关越后面,刷到的装备数值越高,形成"刷关 → 更强装备 → 推更远"的装备驱动循环

### 4.2 每日天赋(数值墙工具)
- 每日 3 个随机天赋(当天固定),**免费领取 1 个,其余看广告解锁**,当日有效次日重置
- 池:战意(伤害+20%)/ 坚韧(生命+30%)/ 淘金(金币+50%)/ 疾咒(触发间隔-15%)/ 幸运(暴击+10%)/ 不屈(复活次数+1)
- 作用:当天"数值墙达标工具"——今天的天赋让你能推今天的关,已解锁的关卡与装备永久保留

## 五、每日重置

- `dailyDate`(YYYY-MM-DD)跨天比对,清零:广告计数、广告回体力次数、商店广告刷新、宝箱领取、扭蛋广告抽、每日天赋;并抽取新一天的天赋
- 存档无版本迁移机制,新字段缺失自动回退默认(体力满 20)

## 六、委托产钻石

- 新增区域「辉钻矿脉」:baseRate 2 钻/小时 × 难度倍率,需 7 次转生解锁,12h 挂满约 60 钻/天
- 委托产出类型扩展:`givesStardust` / `givesDiamond` / 碎片
