# 《回响深渊》需求优化 v2 —— 赛季关卡式 × 场内肉鸽 × 场外养成

> 本文档把核心循环重构为:**每日一关 × 20 章**的肉鸽闯关 + **场内金币买卡(嵌槽/升品/套组)** + **场外跨天养成(天赋/委托/扭蛋/通行证)**,并给出具体曲线与扩充设计。
> 状态:需求稿,内容已全量落地(2026-08-28 起为现网形态);此后被 `DESIGN-V3.md` 与赛季迭代逐轮改写,读本文以「当时的需求锚点」为准,当前事实看 `docs/CONTEXT.md` 与 `docs/README.md` 指向的实现。

---

## 0. 设计核心一句话

> 每天钻研一关:场内杀怪攒金币、买卡、嵌槽、升品,20 分钟打穿一关;场外天赋/委托/扭蛋/通行证提供跨天积累,场外基础属性 × 场内卡牌构筑 = 每一章都紧张刺激的闯关体验。

---

## 1. 关卡结构:七关 × 二十章(层层递进)

### 1.1 七关
- **7 关,层层递进**,按赛季日历**每天只解锁/钻研 1 关**(赛季第 N 天 = 第 N 关)。
- 每关 20 章,每章 **1 分钟**,单局约 **20 分钟**(可中途退出,章间自动存档结算)。
- 关与关之间:怪物强度、卡牌质量、回响奖励全面提升,后关奖励回响更多(见 4.1 曲线)。

### 1.2 二十章(章 = 肉鸽的一层)
每章 = **60 秒限时生存 + 波次递增 + 章末事件**:

| 章节类型 | 位置 | 内容 |
| --- | --- | --- |
| 常规章 | 大部分 | 60s 内 3-5 波,有限竞技场,怪物密度按章递增 |
| 精英章 | 每 5 章(5/10/15) | 波数翻倍 + 精英怪群,奖励商店刷新免费卡 |
| 宝箱章 | 每 7 章(7/14) | 低密度 + 大量金币怪(金怪),鼓励"集火" |
| Boss 章 | 每关第 20 章 | 关底 Boss(机制随关卡变化),胜利 = 通关 |

- **框定区域(非无限)**:每章一个**有限竞技场**(固定尺寸,随章节变化:障碍物、边界、毒池地形),走位空间被压缩 → 紧张刺激感。不同于现在的无限大地图。
- **紧张感来源**:有限空间 + 高密度怪物 + 倒计时,三者叠加。

### 1.3 怪物密度与难度曲线(每章)
- 怪物数量:`第1章 30 只 → 每章 +15% → 第20章 ≈ 480 只/分钟`(每章固定,非无限刷)。
- 怪物血量:`×1.10/章` → 20 章累计 ≈ 6.7 倍;关卡间再 `×1.25/关`。
- 卡牌强度增速略高于怪物(玩家能滚雪球但必须正确构筑):卡牌成长曲线见 2.3。

## 2. 场内循环(肉鸽核心)

### 2.1 金币经济(替代经验宝石)
- **杀怪掉金币**(不再掉经验宝石),金币 = 场内唯一货币。
- 金币怪(金怪):掉 5 倍金币,出现在宝箱章/随机混入。
- 升级概念保留为"章节推进",不再升级三选一装备。

### 2.2 卡牌系统(镶嵌槽位 + 三合一升品)
- **卡牌 = 现有装备三件套的重新包装**:三种卡种——**触发器卡 / 效果卡 / 修饰器卡**,对应现引擎的 trigger/effect/modifier(引擎直接复用)。
- **镶嵌槽位**:每局 **6 槽**(可开 8),卡牌镶嵌进槽位生效;槽位随武器套组有默认类型倾向。
- **购买**:章间(或章内 30s 窗口)刷新商店 3 张卡,金币购买;也可用"回响币"跳过刷新(稀有刷出率随章节提高)。
- **三合一升品**:3 张**同名同品质**卡 → 升一档品质(普通→稀有→史诗→传奇),数值提升 + **解锁一条新词条**;传奇 3 合 1 → 隐藏(彩虹)卡。这是"重复卡有用"的出口,替代现在"重复→星尘"。
- **卡牌图鉴**:见过的卡永久记录,图鉴进度解锁商店稀有度上限。

### 2.3 卡牌价格与货币曲线(核心体验曲线)
- 每章金币获取:`20 × (1 + 章×0.08)` → 第 1 章 20,第 20 章 ≈ 52;单局总金币 ≈ **700**。
- 卡牌基础价(按品质):普通 15 / 稀有 30 / 史诗 60 / 传奇 120。
- **价格随难度/已购递增**:`价格 = 基础价 × (1 + 已购卡数×0.12) × (1 + 章节×0.03)`。
- 目标节奏:前期每章能买 1-2 张(快速成型),后期卡贵但金币多(做取舍);**第 5 章前能凑齐核心卡,第 10 章开始升品,第 15 章后打传奇卡**。
- 需求满足:"卡牌随货币和难度递增,有一个曲线"——曲线公式如上,可在模拟器里跑验证。

### 2.4 武器套组(每赛季 3 套)
- 每个赛季提供 **3 套武器卡组**,场内开局(或章 1)三选一:
  1. **飞刀弹幕流**:多弹/连锁/穿透,适合清群 + 单体兼顾;
  2. **新星爆发流**:高伤单体/范围爆发,适合血厚怪 + 反射型走位;
  3. **召唤毒云流**:骷髅前排 + 毒云控场,适合持久战 + 分裂怪。
- 套组 = **专属卡池**(只能抽到本套组的卡)+ **2/4 件套效果**(集齐触发联动)。
- 场内卡牌"根据武器类型适配不同套组" = 套组卡池隔离。

### 2.5 场内挑战目标(扩充)
- 每章 3 个隐藏目标(如:满血通关/限定时间/无伤),达成给额外金币或回响。
- 首次通关每关给"每日首通奖励"(扭蛋券/回响)。

## 3. 怪物设计:克制关系驱动构筑

| 怪物 | 机制 | 克制它 | 被它克制 |
| --- | --- | --- | --- |
| 血厚型(甲壳) | 高 HP | 高伤单体 | 低伤多弹(刮痧) |
| 分裂型 | 死亡分裂 | AOE / 群体 | 单体高伤(越打越多) |
| 反射者 | 反弹伤害 | 控制节奏/爆发收尾 | 高频弹幕(自伤) |
| 吞噬者 | 吸收投射物回血 | 非投射(新星/召唤) | 投射流 |
| 隐匿者 | 周期性隐身 | 范围预判/召唤物 | 自动瞄准(丢目标) |
| 召唤师 | 持续召小怪 | AOE 清场 | 单体(被淹没) |
| 护盾卫士 | 正面免疫 | 多方向/绕后/AOE | 单方向输出 |
| 金怪(扩充) | 掉 5 倍金币 | 集火 | —— |
| 弹幕型(扩充) | 密集投射物 | 走位/移速卡 | 站桩 |
| 相位型(扩充) | 受击后短无敌 | 控制攻击节奏 | 无脑连发 |
| 光环型(扩充) | 给周围怪加速/加盾 | 优先击杀光环怪 | 不管它 |
| 地形型(扩充) | 毒池/岩浆限制走位 | 免疫类/走位 | 站桩流 |

- 每章怪物构成按曲线混合,后期出现精英(机制叠加)+ 关底 Boss(每关一个主题 Boss,机制随关卡变化)。

## 4. 场外系统(与场内协同)

### 4.1 回响点(跨天主货币)
- **越后关卡奖励回响越多**:第 N 关通关回响 = `10 × N^1.5`(第 1 关 10,第 7 关 ≈ 185)。
- **跨天不完全清空**:
  - **保留**:当天获得的回响点 **50%** 进入跨天池;基础属性(场外道具/收藏加成)永久;攻击形态(上次使用的武器套组)记忆保留。
  - **清空**:场内金币、场内卡牌、当天未领取的关卡奖励。
- 回响用途:天赋加点、赛季通行证进度、商店刷新等。

### 4.2 天赋(场外按钮)
- **主菜单有"天赋"按钮**(现在藏在阵亡结算里,移到场外常驻)。
- 天赋树三系保留,但加点资源改为"跨天回响池"。

### 4.3 委托(场外)
- 委托保持**场外挂机**:产扭蛋券/星尘/材料,与场内关卡并行(玩家推关的同时委托在积累)。
- 产出用途:扭蛋抽收藏、材料强化场外道具。

### 4.4 场外道具(只提供基础属性)
- 收藏装备/场外道具**只提供基础属性**:攻击、生命、攻速、移速、金币加成。
- **不提供卡牌效果**——场内构筑的决策权 100% 留给卡牌,场外只是"底盘"。
- 协同方式:场外基础属性 × 场内卡牌构筑 = 最终战斗力;回响点是跨天纽带。

### 4.5 赛季通行证
- **免费轨 + 高级轨**(支付接入前先做免费轨,高级轨预留)。
- 进度来源:每日通关章数、回响获取、委托完成。
- 奖励:扭蛋券、星尘、场外道具、收藏装备、皮肤/特效、赛季限定卡框。

## 6. 待确认的关键决策

1. **卡牌系统是否完全替代"升级三选一装备"?** 我的建议:是——升级改为商店,卡牌=三件套重包装,现引擎复用,改动集中在"获得方式"。
2. **跨天保留比例**:回响保留 50% 是否合适?(40% 偏硬核,60% 偏轻)
3. **赛季通行证深度**:MVP 先做免费轨?(付费轨需要支付接入)
4. **每章 1 分钟是否含商店时间**(建议不含,章间商店 15-20s 缓冲)。

## 7. 扩充的设计思路(额外想法)

1. **卡牌联动/连锁**:特定组合(如 连锁卡+分裂卡+穿透卡)触发"组合技"特效,鼓励同套组构筑。
2. **章节三选一事件**:部分章节结束时出现三选一事件(回响/金币/卡牌折扣/风险选项),增加肉鸽决策。
3. **每日首通奖励 + 通关星数**:每关按"通关时间/剩余血量"给 1-3 星,星数解锁该关专属奖励。
4. **赛季排行**:按"赛季累计回响 + 全关星数"本地排行,赛季末结算(第 8-14 天无限关冲榜)。
5. **离线挂机与场内的关系**:委托离线积累 → 场外道具强化 → 场内更强,形成"白天推关、夜里委托"的节奏。
6. **稀有度曲线可视化**:卡牌价格/升品曲线接入平衡模拟器,每赛季调一次数值。
7. **攻击形态记忆**:上次使用的套组自动成为下一天默认开局(减少重复选择摩擦)。
8. **怪物图鉴/卡牌图鉴联动**:见过的怪掉对应"研究点",解锁该怪的弱点提示。
9. **Boss 战规则**:每关 Boss 有机制提示(血条/技能预警),失败不扣当天进度,可无限重试(降低挫败)。
10. **金怪与暴击联动**:暴击击杀金怪触发"金币雨",把操作/构筑的正反馈接进经济。
