# 回响深渊 · Echo Abyss

融合 **挂机放置 + 暗黑Like装备驱动 + 吸血鬼幸存者Like尸潮割草** 的自动化构筑类游戏。
本仓库实现策划案(《回响深渊_完整游戏策划案.docx》)的核心循环,并已落地《docs/DESIGN-V3.md》赛季结构(赛季壳/章型差异化/三阶段 Boss/跨套组合技/竞技场地形/幻影榜)。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 → http://localhost:5173(从主菜单进入)
npm run test       # 单元测试(vitest,词缀引擎 + 示例 Build + 各系统 + 平衡模拟)
npm run build      # 生产构建 → dist/
npm run build:minigame && npm run smoke:wechat   # 构建微信小游戏包并冒烟测试
```

**微信小游戏**:`minigame/` 目录已是完整工程,用微信开发者工具导入即可运行(游客模式);详见 `docs/PORTING-WECHAT.md`。

**UI 设计**:`docs/UI-DESIGN.md` 为完整设计规范(色彩/字体/组件/界面线框/动效),落地于 `src/ui/theme.ts`。

**策划配置表**:核心数值平衡(体力/经济/章节曲线/生成节奏/章型/扭蛋)外置于 `public/config/balance.json`,改完刷新即生效;字段说明见 `docs/CONFIG-TABLES.md`,加载器 `src/platform/balance.ts`(校验+非法回退默认),测试 `tests/balance-config.test.ts`。

**美术贴图皮肤**:129 键清单(`src/data/assets.ts`,与 `public/assets/` 一一对应,映射见 `artwork/MAPPING.md`)——按钮板/面板底垫/头像框/星图标/血条/特效等贴图优先(`src/ui/skin.ts` + `drawNine` 九宫格),缺图自动回退代码绘制,布局与命中区域不随皮肤改变。

**画面适配(竖屏全量翻版 v2)**:UI 按 **560 宽设计空间**布局(字阶/控件档位集中在 `src/ui/theme.ts` 设计令牌),设计高随屏幕比例伸展 `clamp(996→1246)`——**手机竖屏(如 1080×2340)顶满无黑边**,桌面(1920×1080)为居中 9:16 列 + 场景背景满溢底。战场恒为 560×996 标定空间(战斗 HUD 为上下双坞,高屏多出的部分是底坞之下的歇指区;刷怪节奏为绝对时间制,不随屏幕尺寸稀释);触摸/点击坐标统一换算回设计空间,命中与绘制像素一致。

## 玩法结构(需求优化 v2:赛季关卡式 × 场内肉鸽 × 场外养成)

- **主菜单**:主线关卡列表 + 无限关 + 扭蛋机 + 天赋 + 通行证(快捷键 1-7/E/G/T/P)。
- **主线关卡(7 关 × 20 章)**:每关 20 章 × **60 秒**限时生存,每章**一屏竞技场**(全屏可见,无镜头移动);关底结算:**7 关第 20 章均出 Boss,杀 Boss = 通关,超时未杀判负**;偶数关(2/4/6)Boss 为**弱化变体**(血量 ×0.7、跳过二阶段、死亡不分裂);章间**商店**(金币买卡,玩家手动开始下一章)。通关解锁下一关,回响奖励随关卡递增(10×N^1.5)。
- **自主控制(挂机)**:角色默认自动移动(贴身才躲、平时巡场)+ 全自动战斗/拾取,手动输入可接管;F6 切换挂机/手动,HUD 显示状态。
- **英雄节律 × 独有技能 × 法宝(`docs/DESIGN-HERO-RHYTHM.md`)**:触发条件不再是卡上的随机词条,而是**英雄本命节律**(受击/周期/击杀/移动/连杀/低血,12 英雄各 2 人);**升级三选一**只发**英雄独有技能**(核心 1 + 互斥分岔 2 + 进阶 1,各 5 阶;分岔选中即解锁第 2 节律;每章 1 次免费重随、锁 1 张;技能池耗尽出兜底);**章间商店**只卖**法宝**——主动法宝 14 = 现效果层(不带修饰器,挂在已解锁节律上发动,点行可切节律,挂到共鸣节律上改名变形)、被动法宝 8+2 = 现修饰器层升格为全局乘区(被动槽 4,同款叠加按 0.6 递减);进第 1 章前**首章法宝三选一**(免费,至少 1 张共鸣)。**共鸣**是质变点:法宝挂到共鸣节律上、技能拿到共鸣被动都会改名变形,首次达成有横幅 + 0.4s 时停并入图鉴;本局共鸣 2 / 4 处激活原套组两档联动加成(套装件数退役)。**赛季共鸣**(R5):S2 起每季 3 对新「法宝 × 节律」共鸣格 + 1 枚赛季法宝(霜牢符 / 熔核符 / 招魂符,当季商店偏向、过季常驻),过季新格降为回响共鸣(改名保留、补丁减半);发现横幅带「本季新共鸣 / 回响共鸣 / 本季首发」角标。被动池另含 8 枚**遗物**(命运骰 / 裂核 / 沙漏 / 透镜 / 稳定器 / 磁轭 / 护心镜 / 假命,修饰器 : 遗物 = 2 : 1)。升级弹层可花金币**重置分岔**(每局 1 次)。各英雄核心技能按旧武器射速带**节律调率**(凯尔 / 诺拉 1.2s 齐射、洛卡 3 连杀、多兰 168 步、希雅七成血),事件节律核心另带 3s **底拍**保证冷启动。**界面两列表**:战斗 HUD 底坞上排独有技能、下排主动法宝(排间分隔线),章间商店在槽位钮下方多一段只读「独有技能」行(名 / 类别 / 节律 / 阶数)。**召唤物跨章保留**:骷髅 / 狼 / 亡影随主人进下一章,剩余存活照常倒数。**精英章**(5 / 10 / 15)章首 6 秒只有密度,第 6 秒起精英入场并打横幅。HUD 每张卡底两条细条:CD 条(周期 / 底拍)与节律进度条(连杀 / 移动 / 低血攒到几成)。跨局:该英雄任一关 3 星通关解锁**第二本命**,英雄页第 4 行点行切换,开局核心技能与挂机档随之切换。S1 三英雄 + S2 三英雄(希雅 / 诺拉 / 洛卡)有专属技能表,其余走通用职业包。
- **场内金币经济**:杀怪掉金币;章间商店买法宝(主动槽基础 4,天赋最多 +2、本局广告 +1,硬顶 6;被动槽 4,天赋「被动槽扩展」+1),价格随购买数与章节递增;**场内成长双轨**:强化(任意法宝金币升级,数值增长)+ 进化(2 张同款升档,形态变化;3 张免费);等级每级 +8 最大生命;攻击射程 640 覆盖全屏。
- **荆棘反伤回血流(受击类联动)**:受击/受伤触发卡 + 吸血/汲取/护盾回血来源 同时在场时激活——每次挨打回 2% 生命,受击/受伤触发的效果伤害 +50%;商店会配对互补卡引导凑齐流派(有荆棘补回血、有回血补荆棘),HUD 显示"荆棘回血"提示。
- **武器套组(常驻 3 套 + 赛季限定套)**:主菜单选套组(荆棘回响/弹幕风暴/余烬天灾,再点取消=通用池);套组=效果派系,装备 2/4 件激活联动(受击回血/弹幕+1/范围+18% 等);商店 60% 偏向刷本套卡(卡面"套"角标);**选套即定本局基调——开局初始武器换成套组专属**(荆棘圆环·受击爆发 / 寒霜风暴·全屏减速弹幕 / 连闪天火·闪电连锁 / 极北权杖·霜环扩散 / 熔核之心·陨星落点 / 影群哨笛·灵狼协战)。
- **赛季新鲜感三层(DESIGN-SEASON-SETS,`src/data/seasonSets.ts`)**:① **L1 主题**——4 主题循环(回响苏醒/永冻深渊/熔火回响/幽冥潮汐),带主题色与 `envBias` 环境词缀加权;② **L2 赛季联动词缀**——常驻三套各 5 条 mutation 池按 `pool[(seasonId-1)%5]` 轮换,±15% 内的 stat 级 patch 走 `ctx.setBonus` 实时折入,并定向商店首个修饰器;③ **L3 赛季限定套组**——frost/magma/phantom 按 `releaseSeason` 2/3/4 上市,当季商店偏向 60%→70% + 双 patch 专属词缀,过季永久保留可选但加成自动回落。全部为 `seasonId → 纯函数`(同赛季恒同配置),只作用玩家侧、不折入怪物曲线。
- **章节敌情(克制导向)**:每章 4 类敌情轮转(尸潮/重甲/异变/精英),HUD 与商店显示"敌情+推荐套组";本章主力敌种更频繁出现且 +40% 血量,不针对就压力陡增。
- **首局引导**:新玩家第 1 关自动弹出 6 步顺序教学(自动挂机→金币→买卡→套组→强化与进化→章节/敌情),每条 8 秒自动隐藏,可点「跳过」永久关闭(存档 tutorialDone)。
- **赛季壳(DESIGN-V3 §4)**:14 天赛季——关卡按**进度**解锁(通关前一关,或前一关打到 `ceil(20 × 50%) = 10` 章;比例由 `battle.stageUnlockProgress` 可配),无限关常开,**均不按天数门控**;每关通关记 1-3 星(通关 ★ + 生命≥50% ★ + 未用复活 ★);**每日首通**券 ×2 / 回响 ×1.5;**补星**(恰好 2 星可花 5 钻补 3 星)与**补领**(当日未首通可看广告领同口径奖励,每日 1 次);3 星首达发券 ×5 并解锁该关头像框(贴图皮肤已接入幻影榜/胜利面板,缺图回退代码金圈);赛季分 = Σ(星数×10) + 赛季最佳(主线章节数与无限关波次同口径取大),赛季结束按 1:1 结算星尘。
- **章型差异化 + 金怪(§3)**:20 章 = 普通×14 / 精英×3(第 5/10/15 章,密度 ×1.3 + 开局 burst ×1.5 + 强制精英敌情)/ 宝箱×2(第 7/14 章,稀疏 ×0.5 + 25% 金怪,单只掉 16 金)/ Boss×1。

- **跨套组合技 + 竞技场地形(§4)**:三种"三词缀同时在场"组合技——弹幕风暴(连锁+分裂+穿透)/深渊裂隙(新星+毒云+汲取,新星落点留回血池)/荆棘光环(护盾+吸血+受击触发,反弹 30%);地形 = 石柱挡路(推挤)+ 毒池 DoT(6/秒),每章重生成,第 1 章与 Boss 章净空。
- **幻影榜(§4.3)**:本地模拟排行——由赛季分种子生成 10 个固定幽灵分(同 `seasonId` 恒同榜,顶两名走独立基准 233/213 使投入度可区分、榜首现实可达),赛季翻页自动换榜;玩家超过对手即"超越"提示。**名次只做实时对照,结算仍按赛季分 1:1 发星尘,无按名次发奖**。真排行待后端。
- **体力与广告(商业化)**:体力上限 20、6 分钟回 1;主线 5-8/关、无限关 3;8 个激励视频点位(死亡复活/结算双倍/体力补充/商店刷新/每日宝箱/扭蛋免费抽/补领/通行证高级轨);钻石硬通货(看广告 +1,每日上限 10)。
- **无限关(爽模式)**:无尽章节,随机环境词缀。
- **场外系统**:天赋/委托/扭蛋/通行证从主菜单进入;**回响跨天保留 40%**(60% 入本日池,次日清空,F5 模拟次日);**双轨通行证**(免费 + 高级 ×2 奖励,高级轨看广告激活、仅本赛季有效,赛季翻页需重新激活);扭蛋收藏提供基础属性。

## 操作

- **桌面端**:WASD / 方向键移动(默认挂机自动移动,手动输入即接管);攻击完全由装备的自动化规则执行(策划案 2.3)
- **移动端**:屏幕左半区拖动虚拟摇杆
- **章间商店**:每章 60 秒结束后进入商店——金币买卡/强化/进化/购槽,Enter 或点按钮开始下一章
- **阵亡/通关**:结算回响点数与星数(通关),返回主菜单;阵亡可选看广告复活(每局 1 次)
- **天赋树界面**:点击节点购买(需满足层级解锁),配置定向搜索/完美蓝图后开始新对局

## 已实现(核心循环 MVP)

- **装备词缀引擎**(策划案 3.2/3.3 全量):
  - 6 种触发器:周期脉冲 / 击杀触发 / 受伤反应 / 移动触发 / 受击触发 / 连杀触发
  - 8 种效果:飞刀投射 / 火焰新星 / 召唤骷髅 / 生成毒云 / 冰霜射线 / 闪电链 / 护盾生成 / 生命汲取
  - 8 种修饰器:连锁 / 爆炸 / 分裂 / 吸血 / 穿透 / 加速 / 增幅 / 持续
  - 4 种品质(普通/稀有/史诗/传奇)按"触发器数+效果数+修饰器数"规则随机构成,品质随等级上移
- **战斗循环**:自动攻击 → 击杀掉金币 → 章间商店买卡/强化/进化 → 下一章(每章 60 秒,一屏竞技场)
- **数值平衡(实测调优)**:血量曲线前 5 章 +2%/章、之后 +7%/章(第 20 章 ≈2.15 倍);反射伤害每秒上限 = 最大生命 15%(防高爆发 Build 被反射者反伤自毁);`npm test` 内置平衡模拟器(`tests/balance.test.ts` / `scripts/balance-sim.ts`),用真实战斗系统跑长局验证曲线
- **战斗爽感(弹幕反馈)**:飞刀/射线基础**扇形多发**(spread 1-3,初始武器 3 发);**连杀狂潮**——连杀 3 秒内不断连,每 10 连杀触发 2 秒狂潮(全装备触发间隔 ×0.6,击杀链变成弹幕风暴);击杀带爆裂反馈特效
- **尸潮波次**:章节内生成间隔 0.9s 起、随章节递减(第 6 章起放缓),下限 0.18s;章节开局刷一波怪;关内敌人血量按章递增
- **敌人类型(策划案 4.3)**:基础 腐尸/迅捷鬼/石巨/精英 + 六种特化敌人按章节登场:
  - 反射者(反弹伤害给目标)、分裂体(死亡后分裂 2 个幼体)、隐匿者(周期性隐身,隐身时不可被瞄准/命中)
  - 吞噬者(吸收投射物回血,克制远程投射)、护盾卫士(正面 60° 内伤害减免 80%,多方向/AOE 可绕过)、召唤师(每 4 秒召唤小怪)
  - 敌人贴身停驻围圈,不会与玩家重合
  - 另有:金怪(宝箱章,掉 16 金)、神级敌人(天赋「神之挑战」解锁后波 8 起 4%)、深渊领主 Boss(第 20 章,三阶段)
- **环境词缀(策划案 4.2)**:每局随机 1-3 个改变战场规则——
  - 反伤领域(敌人受击反弹 12%)、治疗光环(敌人每秒回 2%)、空间扭曲(投射物轨迹弯曲)
  - 时间膨胀(脉冲间隔翻倍)、死亡连锁(敌人死亡爆炸波及周围)、隐匿迷雾(所有敌人周期性隐身)
  - HUD 常驻显示本局环境词缀
- **升级成长**:装备槽基础 4 个(天赋最多 +3,商店可购槽位,硬顶 `SHOP_SLOT_CAP=8`),同触发器类型冲突替换(策划案 3.3)
- **转生系统(策划案 5.2/5.4)**:

## 架构

```
src/
├── main.ts                    # 入口 + 调试接口
├── game.ts                    # Game 主类:组装/渲染/战斗结算/状态机
├── platform/                  # adapter(浏览器 ↔ 微信小游戏) / assets(贴图加载)
├── core/                      # math(向量/随机) / input(键鼠+摇杆)
├── data/                      # affixes / equipmentGen / sets / combos / stages / chapters / intel / season / leaderboard / daily / talents ...
├── systems/                   # equipmentEngine(词缀引擎) / waves(尸潮) / save(存档) / onboarding(引导)
├── ui/                        # theme(主题) / skin(贴图皮肤助手)
└── entities/                  # player / enemy / projectile / objects(毒云·骷髅·地形障碍)
tests/                         # 22 个测试文件(词缀引擎/各系统/平衡模拟)
```

**设计要点**:

- 词缀引擎只通过 `BattleContext` 读写世界,不碰渲染与平台 API,可独立单测。
- 实体数组用**原地修改**(`removeIf`)清理,不用 `arr = arr.filter(...)` 重新赋值——BattleContext
  持有数组原始引用,重新赋值会导致引擎看到陈旧数组(飞刀打不进新数组、引擎看不到新敌人)。
- 开局装备固定为"周期脉冲 + 飞刀投射":触发器必须不依赖击杀即可生效,否则开局无法破局。
